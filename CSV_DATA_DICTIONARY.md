# CSV Data Dictionary

This document describes the CSV and reference files generated by the `.NET` Spirits to BottlePOS Migration Utility and where each value comes from in the source Spirits/KSV DBF data.

The mappings below reflect the current `.NET` export behavior in `dotnet/SpiritsToBottlePOSMigrationUtility/Services/MigrationService.cs`.

Current documented version: `7.2.26`

## Common Formatting Rules

- Text values are generally trimmed, converted to uppercase, and double quotes are removed.
- Multi-line text is flattened by replacing line breaks with spaces.
- Money values are rounded to 2 decimal places and written with 2 decimal places.
- Sale price reference values are rounded to 4 decimal places and written with 4 decimal places.
- Whole-number values are truncated, not rounded.
- SKUs are written as text. SKUs shorter than 6 characters are left-padded to 5 characters. SKUs with 6 or more characters are left unchanged.
- The active store is read from the first row in `STR.DBF` using the `STORE` field. Inventory, stock, and sale-price logic uses that store where noted.
- Generated CSV and reference files are packaged into a ZIP archive after export.

## `1_departments.csv`

One row is written for each `TYP.DBF` row whose `SCAT1` value matches a category code in `CAT.DBF`.

| CSV column | Source data | How the value is built |
| --- | --- | --- |
| `ImportType` | Constant | Always `D`. |
| `category_name` | `TYP.DBF.NAME` | Cleaned uppercase department/type name. |
| `category_group_name` | `TYP.DBF.SCAT1` matched to `CAT.DBF.CAT`, then `CAT.DBF.NAME` | `SCAT1` is treated as the category group code. Rows are skipped when the group code is blank, unmatched, or resolves to a blank category name. |

## `2_vendors.csv`

One row is written for each `VND.DBF` row.

| CSV column | Source data | How the value is built |
| --- | --- | --- |
| `ImportType` | Constant | Always `V`. |
| `suppliername` | `VND.DBF.LASTNAME`, `VND.DBF.FIRSTNAME` | Last name and first name joined with a space, then cleaned uppercase. |
| `firstname` | `VND.DBF.CONTACT` | Contact name, cleaned uppercase. |
| `address` | `VND.DBF.STREET1`, `VND.DBF.STREET2` | Street 1 and street 2 joined with a space, then cleaned uppercase. |
| `phone` | `VND.DBF.PHONE` | Removes `"`, comma, plus, at sign, number sign, dash, parentheses, question mark, and spaces. |
| `email` | `VND.DBF.EMAIL` | Cleaned uppercase email value. |

## `3_customers.csv`

One row is written for each `CUS.DBF` row.

| CSV column | Source data | How the value is built |
| --- | --- | --- |
| `ImportType` | Constant | Always `C`. |
| `mobile` | `CUS.DBF.PHONE` | Removes `"`, comma, plus, at sign, number sign, dash, parentheses, question mark, and spaces. If the result is `0`, the CSV value is blank. |
| `firstname` | `CUS.DBF.FIRSTNAME`, sometimes `CUS.DBF.LASTNAME` | First name cleaned uppercase. If first name is blank and last name is present, last name is moved into `firstname`. |

| `address` | `CUS.DBF.STREET1`, `CUS.DBF.STREET2` | Street 1 and street 2 joined with a space, then cleaned uppercase. |

| `houseacclimit` | `CUS.DBF.CRDLIMIT` | Truncated whole number. |
| `housesaleborrow` | `CUS.DBF.BALANCE` | Money formatted to 2 decimal places. |
| `ishousepay` | `CUS.DBF.CRDLIMIT` | `1` when truncated credit limit is greater than `0`; otherwise `0`. |

## `4_inventory.csv`

One row is built for each `INV.DBF` item. By default, inactive items are excluded from `4_inventory.csv`; if the `Include inactive products` option is selected, inactive items are included.

Inventory stock data is taken from `STK.DBF` rows for the active store. If multiple stock rows exist for the same SKU and store, the export uses the maximum value for `FLOOR`, `BACK`, `ACOST`, `LCOST`, and `MINCOST`, and the maximum cleaned string value for `PVEND`, `LVEND`, and `STAT`.

Pricing rows come from `PRC.DBF` rows where `QTY > 0`. If `Use Price Level` is selected, only the selected level, `1`, `2`, or `3`, is used. Otherwise levels `7`, `8`, and `9` are excluded. When pricing rows exist for both the active store and other stores, active-store rows are preferred. If no active-store rows exist, store `1` is preferred.

| CSV column | Source data | How the value is built |
| --- | --- | --- |
| `ImportType` | Constant | Always `I`. |
| `code` | `UPC.DBF.UPC` where `UPC.DBF.SKU = INV.DBF.SKU` | Uses nonblank UPC values that contain only digits. Duplicate UPCs are removed, values are sorted, joined with commas, and limited to 250 characters. This column remains unchanged by the UPC-to-QTY linking logic. |
| `CodeToQTY` | `UPC.DBF.UPC`, `UPC.DBF.LEVEL`, selected `PRC.DBF.LEVEL`, selected `PRC.DBF.QTY` | Contains only UPC codes that can be linked one-to-one to a selected price quantity. Values are ordered by the numerical order of the linked quantity. |
| `LinkedQTY` | Selected `PRC.DBF.QTY` linked through matching `UPC.DBF.LEVEL` and `PRC.DBF.LEVEL` | Contains the quantities linked to `CodeToQTY`. The first value in `LinkedQTY` belongs to the first value in `CodeToQTY`, the second belongs to the second, and so on. |
| `sku` | `INV.DBF.SKU` | Formatted SKU text. |
| `name` | `INV.DBF.NAME` | Cleaned uppercase item name, line breaks replaced with spaces, limited to 100 characters. |
| `cost` | `STK.DBF.ACOST`, `INV.DBF.PACK`, selected `PRC.DBF.QTY` | Average unit cost is `ACOST / PACK`, rounded to 4 decimals using banker's rounding. `PACK` defaults to at least `1`. CSV cost is average unit cost multiplied by the default price quantity, then money formatted. |
| `lastcost` | `STK.DBF.LCOST`, `INV.DBF.PACK`, selected `PRC.DBF.QTY` | Same as `cost`, but starts from last cost `LCOST`. |
| `price` | Selected `PRC.DBF.PRICE` | Uses the first unique selected price quantity after pricing rows are ordered by quantity and original source order. Money formatted. If no price rows exist, `0.00`. |
| `minprice` | `STK.DBF.MINCOST` | Money formatted when greater than `0`; otherwise blank. |
| `DONOTDISCOUNT` | `PRC.DBF.DCODE` matched to `DSC.DBF.DCODE`, with `DSC.DBF.LEVEL1DISC = 0` | `TRUE` when any preferred discount code for the SKU is marked non-discountable; otherwise blank. |
| `qty` | `STK.DBF.BACK`, `STK.DBF.FLOOR`, selected `PRC.DBF.QTY` | If `Add QTY=1 if missing` is selected, quantity is `BACK + FLOOR`. Otherwise quantity is truncated `BACK / inventory quantity divisor`. The inventory quantity divisor is the smallest selected priced quantity when available, otherwise the smallest selected quantity, otherwise `1`. Result is rounded to 3 decimals for output. |
| `unitspercase` | `INV.DBF.PACK`, selected `PRC.DBF.QTY` | `PACK / inventory quantity divisor`, truncated to a whole number. If the divisor is zero or less, uses `PACK`. |
| `POINTSMULTIPLIER` | `INV.DBF.FSFACTOR` | Only values `1`, `2`, `3`, `4`, and `5` are exported. Any blank, fractional, zero, negative, or out-of-range value exports as `1`. |
| `taxname` | `INV.DBF.CAT` matched to `CAT.DBF.CAT`; tax setup from `CNT.DBF` and `TXC.DBF` | If the item's category has `CAT.DBF.TAXLEVEL > 0`, uses the sales tax name from `CNT.DBF` code `CUSTAX` matched to `TXC.DBF.CODE`. The name is `TXC.DBF.DESCRIPT`, or `TXC.DBF.CODE` if description is blank. If `TAXLEVEL = 0`, uses `NoTax`. Otherwise blank. |
| `taxrate` | `TXC.DBF.RATE` through the same sales tax lookup as `taxname` | For taxable items only, `TXC.DBF.RATE * 100`, rounded to 2 decimals. Blank for `NoTax` and unknown tax category rows. |
| `categoryname` | `INV.DBF.TYPENAME` | Cleaned uppercase type name. Defaults to `MISC` when blank. Limited to 50 characters. |
| `suppliername` | `STK.DBF.LVEND` or `STK.DBF.PVEND`, matched to `VND.DBF.VCODE` | Uses `LVEND` when present, otherwise `PVEND`. The vendor name is built from `VND.DBF.LASTNAME` and `VND.DBF.FIRSTNAME`. Defaults to `UNKNOWN` when no vendor name is found. Limited to 50 characters. |
| `vendoritemno` | `UPC.DBF.UPC`, `UPC.DBF.LAST` where `UPC.DBF.SKU = INV.DBF.SKU` | Uses UPC rows whose raw UPC contains non-digit characters. Digits are extracted, duplicates are removed using digits plus `LAST`, values are ordered by newest `LAST` first, and only values up to 10 digits are kept. Joined with commas and limited to 250 characters. |
| `Unit_Size` | `INV.DBF.SNAME`, fallback parse from `INV.DBF.NAME` | If `SNAME` is blank or `N/A`, attempts to find a pack size from item name text such as `6PK`; otherwise defaults to `1`. When `SNAME` is present, digits and decimal characters are extracted. Limited to 10 characters. |
| `Unit_Type` | `INV.DBF.SNAME`, fallback parse from `INV.DBF.NAME` | If item name pack parsing succeeds, type is `PK`. If `SNAME` is present, letters are extracted. `O` and `Z` become `OZ`. If type is missing and size is `750` or `500`, type becomes `ML`; if size is `1.5` or `1.75`, type becomes `L`. Otherwise defaults to `N/A`. Limited to 20 characters. |
| `ModifiersQty` | Additional selected `PRC.DBF.QTY` rows | Additional unique quantities after the default price quantity. If the base quantity is `1`, uses the raw modifier quantity. Otherwise uses modifier quantity divided by base quantity and rounded to a whole number. Values are comma-separated and limited to 100 characters. |
| `ModifiersCost` | Additional selected `PRC.DBF.QTY` rows, `STK.DBF.ACOST`, `INV.DBF.PACK` | For each modifier quantity, average unit cost multiplied by that quantity, money formatted. Values are comma-separated and limited to 100 characters. |
| `ModifiersLatestCost` | Additional selected `PRC.DBF.QTY` rows, `STK.DBF.LCOST`, `INV.DBF.PACK` | For each modifier quantity, last unit cost multiplied by that quantity, money formatted. Values are comma-separated and limited to 100 characters. |
| `ModifiersPrice` | Additional selected `PRC.DBF.PRICE` rows | Additional selected prices after the default price quantity, money formatted. Values are comma-separated and limited to 100 characters. |
| `notes` | `INV.DBF.MEMO` | Line breaks are replaced with spaces. The text is reduced to 250 characters before repeated spaces are collapsed, then cleaned uppercase and limited to 100 characters. |
| `bottledeposit` | `INV.DBF.DEPOS`, selected `PRC.DBF.QTY` | Blank when `DEPOS` is blank. Otherwise uses the effective package quantity followed by `PK`, such as `1PK` or `6PK`. Effective package quantity is the smallest selected quantity, unless `Add QTY=1 if missing` is selected and no quantity `1` exists, in which case it is `1`. |

### UPC-To-QTY Linking Rules

The UPC-to-QTY logic uses the existing Spirits hierarchy. It does not add `UPC.LEVEL` or `PRC.LEVEL` to `4_inventory.csv`.

A UPC is linkable only when all of these conditions are true:
- `UPC.DBF.SKU` matches `PRC.DBF.SKU`.
- The UPC is numeric.
- `UPC.DBF.LEVEL` is not blank.
- `UPC.DBF.LEVEL` matches one selected `PRC.DBF.LEVEL`.
- The matched `PRC.DBF.LEVEL` resolves to one selected `PRC.DBF.QTY`.
- The linked quantity is used by only one UPC for that SKU.

When a UPC is linkable:
- the UPC is added to `CodeToQTY`
- the linked quantity is added to `LinkedQTY`
- both fields are ordered by linked quantity
- the UPC remains in the original `code` column

When a UPC is not linkable, it remains in `code` and is written to `reference_UPCModifierLinkAudit.html`.

Common unlinkable conditions include:
- no selected PRC quantity exists for the SKU
- the UPC appears under multiple UPC levels
- `UPC.LEVEL` is blank
- the matching PRC level has more than one quantity
- no selected PRC level matches the UPC level
- more than one UPC links to the same quantity

### Inventory Inactive Status

Inactive status is based on the selected store's `STK.DBF.STAT` value for the SKU.

- Active stock statuses are `2` and `8`.
- Any other status is treated as inactive.
- Inactive items are always written to `reference_InactiveItems.csv`.
- Inactive items are written to `4_inventory.csv` only when the `Include inactive products` option is selected.

### Inventory QTY=1 Option

`Add QTY=1 if missing` is off by default.

When selected and a SKU has pricing rows but none with `QTY = 1`, the export adds an internal unit price row:

- Quantity is `1`.
- Price is the first selected non-unit price divided by its quantity, rounded to 2 decimals.
- This generated row can become the default inventory `price`.

## `reference_InactiveItems.csv`

This file uses the exact same columns and value logic as `4_inventory.csv`.

Only inactive items are written to this file. The file is always generated when inventory is selected, even if it contains only the header row.

See the `4_inventory.csv` section for the full column dictionary.

## `reference_SalePrices.csv`

This file is generated when inventory export is selected.

Rows come from `PRC.DBF` rows for the active store where `ONSALE` is true. The sale-price reference export does not apply the inventory price-level filtering described above. Sale pricing is not written to `4_inventory.csv`.

| CSV column | Source data | How the value is built |
| --- | --- | --- |
| `SKU` | `PRC.DBF.SKU` | Formatted SKU text. |
| `SALE_PRICE` | `PRC.DBF.SALE` | Rounded and formatted to 4 decimal places. |
| `REGULAR_PRICE` | `PRC.DBF.PRICE` | Rounded and formatted to 4 decimal places. |

`PRC.DBF.ONSALE` is treated as true for boolean true values and common true text values such as `T`, `.T.`, `TRUE`, `Y`, or `1`.

## `reference_UPCModifierLinkAudit.html`

This file is generated when inventory export is selected.

It contains only UPC codes that could not be safely added to `CodeToQTY` and `LinkedQTY`. Linkable UPC codes are not included in the audit report.

| Report column | Source data | How the value is built |
| --- | --- | --- |
| `SKU` | `UPC.DBF.SKU` | Formatted SKU text. |
| `UPC` | `UPC.DBF.UPC` | The unlinkable UPC code. |
| `UPC_LEVEL` | `UPC.DBF.LEVEL` | The UPC level that was evaluated. Blank when the source level is blank. |
| `PRC_LEVEL` | Selected `PRC.DBF.LEVEL` | The matched PRC level when one exists. Blank when there is no match. |
| `ISSUE` | Link audit logic | A clickable memo link. The memo text is embedded in the HTML report and explains why the UPC was not linked. |

The audit report starts with an issue-count summary, followed by the row-level audit table and embedded row memos.
